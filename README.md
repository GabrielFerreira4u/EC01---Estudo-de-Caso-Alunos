# Estudo de Caso – Alunos (Bootstrap)

Sistema de cadastro de alunos em HTML + JavaScript (dados em memória) com interface em Bootstrap 5:
CRUD, classe `Aluno`, avisos com alerts do Bootstrap e relatórios com `filter`, `map`, `reduce` e `sort`.

O Bootstrap é carregado por CDN, então é preciso ter internet ao abrir a página.

## Rodando com Docker
```bash
docker compose up --build
```
Acesse http://localhost:8080
